- 2026-11-19 — v1.77 (125) — Loading a new version is light, and survives a dropout. Yu Chen, 21:30: "we have difficulty and delay time of loading a new version" — his own practice phone would not come off the old version at all. Two faults in sw.js, both measured against the old code before the fix: every release pulled all 44 files again, **1,621 KB for a release that changed 230 lines**, because each was asked for with cache: 'reload' — "ignore anything you have, send it again" — so look.css, lot-shapes.js and the icons (366 KB, unchanged in four weeks) came down every time; and addAll is one batch, so ONE file dropping out on an estate line failed the whole install and the phone stayed on the old version with no error and nothing to show for the wait. New test v86-update-path runs its own copy of the site on its own port so it can break files on purpose, and checks all three things that matter: the switch happens, a dropped file does not kill it, and E-Book still opens with the network off.
